# Задача 02. Выбор замены MinIO

Раздел постановки: 4; 7, задача 2.
Зависит от: 01 (перечень обязательных S3-операций).
Блокирует: 03.

## Цель

Выбрать S3-совместимое хранилище, которое работает с нашей версией ELMA365, держит ~12 млн мелких объектов на одном сервере с HDD в RAID6 в бюджете ВМ 16 ГБ / 8 потоков и сопровождается своими силами.

## Контекст

- Основной кандидат: **SeaweedFS** (упаковка мелких объектов в тома, работа на одном узле). Окончательно не выбран.
- Ceph отклонён для текущей конфигурации: один физический сервер не даёт независимых областей отказа.
- Наличие S3 API не равно совместимости с ELMA365.
- 63% объектов меньше 256 КБ: для HDD важно, сколько случайных операций приходится на один объект при записи и чтении.

## Что сделать

- [ ] Составить матрицу требований из задачи 01: каждая обязательная S3-операция, адресация бакета, SigV4, presigned URL, Range, метаданные, теги, multipart с нужными размерами частей.
- [ ] Для SeaweedFS выбрать конкретную версию, изучить: где хранятся метаданные filer (встроенный LevelDB или внешняя БД), требования к памяти на число объектов, как ведёт себя volume на RAID6, есть ли актуальные релизы и исправления безопасности.
- [ ] Поднять стенд (можно на временной ВМ с ограничением 16 ГБ / 8 потоков) и прогнать:
  - функциональные проверки по матрице (скриптом на boto3);
  - подключение тестового контура ELMA365 к отдельному бакету: загрузка, предпросмотр, скачивание, удаление, большие файлы;
  - нагрузку: запись и чтение 1–2 млн объектов с распределением размеров как в постановке, замер объектов/с, потребления памяти и поведения после рестарта;
  - листинг с большим числом ключей (он понадобится в задаче 10).
- [ ] Если SeaweedFS не проходит, взять следующего кандидата и повторить с той же матрицей. Кандидаты фиксировать в разделе «Решения».
- [ ] Уточнить у поддержки ELMA позицию по выбранному продукту.

## Риски по времени

- Нагрузочный тест на миллионах объектов сам занимает часы-сутки. Генерацию тестовых данных и прогоны запускать в фоне и ночью.
- Подключение тестового ELMA365 может зависеть от другой команды: запросить заранее.

## Результат

Записка с выбранным продуктом и версией, матрицей совместимости, результатами нагрузочного теста, известными ограничениями и обоснованием отказа от других кандидатов.
