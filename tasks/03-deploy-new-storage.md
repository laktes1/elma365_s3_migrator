# Задача 03. Развёртывание нового хранилища

Раздел постановки: 2 «Новая инфраструктура»; 7, задача 3.
Зависит от: 02.
Блокирует: 08.

## Цель

Получить работающее новое S3 на выделенной ВМ физического сервера с проверенной процедурой восстановления метаданных.

## Контекст

- Сервер: системный SSD + 8 × HDD 5 ТБ за аппаратным RAID-контроллером, предлагается RAID6 (~27,3 ТиБ до форматирования).
- ZFS RAIDZ2 поверх аппаратного RAID не используется. Вторая пара SSD не закуплена.
- Метаданные/индексы на единственном системном SSD — отдельный риск отказа.
- Бюджет ВМ: 16 ГБ RAM, 8 потоков.
- Источник растёт на 80–100 ГБ в месяц, нужно заложить запас.

## Что сделать

### Железо и массив
- [ ] Подтвердить фактическую конфигурацию RAID (уровень, stripe size), модели HDD, прошивку и состояние контроллера, наличие BBU/флеш-защиты кеша и режим кеша записи.
- [ ] Проверить скорость массива на случайной записи/чтении мелкими блоками (fio) из ВМ, а не только с хоста.
- [ ] Посчитать ёмкость: логический объём из задачи 01 + накладные расходы выбранного продукта + рост на срок эксплуатации.

### ОС и хранилище
- [ ] Выбрать файловую систему для томов данных и для метаданных, параметры монтирования.
- [ ] Решить размещение метаданных/индексов (SSD или HDD) с учётом отказа единственного SSD.
- [ ] Установить выбранную версию хранилища, настроить автозапуск, лимиты памяти, журналы.
- [ ] Создать бакет, отдельные ключи доступа для ELMA365, для шлюза/обработчиков и для администрирования. Настроить TLS.

### Мониторинг и восстановление
- [ ] Мониторинг ёмкости, SMART, состояния массива, доступности S3 и задержек.
- [ ] Резервное копирование метаданных хранилища (например, filer-БД для SeaweedFS) и его проверка восстановлением на чистую ВМ.
- [ ] Описать, что происходит при отказе SSD, ВМ и всего сервера; сколько времени занимает восстановление.

## Риски по времени

- Перестройка RAID-массива после ошибки конфигурации занимает дни; настройку массива проверить до наполнения данными.
- Проверку восстановления метаданных делать на тестовых данных сразу, а не после переноса 12 млн объектов.

## Результат

Работающее новое S3 с тестовым бакетом, инструкция по развёртыванию, мониторинг, проверенная процедура восстановления метаданных.
